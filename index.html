Swarf (Machining Simulation Engine)

C++20 • CMake • OpenGL • Raylib
Active Development

The Engineering Challenge

Developing a cross-platform, real-time machining simulation tool that requires zero-latency execution and complex mathematical modeling without relying on pre-built commercial game engines.

Architecture & Implementation

  • Engineered a custom Signed Distance Fields (SDF) volumetric engine utilizing OpenGL and Raylib for hardware-accelerated rendering.
  • Implemented a complete GCode Parser with Macro Functions to accurately interpret and simulate industrial CNC instructions.
  • Applied modern C++20 memory management techniques (smart pointers, move semantics) to ensure continuous optimizations and prevent memory leaks during prolonged simulation runs.

Vineyard Telemetry Fetcher

Rust • JavaScript • Chart.js • REST APIs
In Production

The Problem

A third-party agricultural software vendor provided insufficient historical data storage for field temperature sensors, limiting long-term climate analysis for a vineyard.

Solution & Execution

  • Engineered a lightweight, high-performance data extraction service in Rust to automatically consume the vendor's REST API and safely pull data off-site.
  • Bypassed the storage constraints by creating a robust local data-store for historical telemetry persistence.
  • Developed an interactive, web-based dashboard using JavaScript and Chart.js, allowing stakeholders to visualize long-term hardware sensor trends instantly.
Field Sensor → Vendor API → Rust Telemetry Fetcher → Local Storage → JS Dashboard
